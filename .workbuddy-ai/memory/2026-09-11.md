## Astra 界面设计方案（design/）

为 Astra 交付了完整的新界面设计方案，覆盖双主题与全部五个页面。

**产物**（均在 `design/`，零依赖单文件 HTML，可直接浏览器打开）
- `astra-design-system.html` — 设计系统规范：令牌可视化、双主题对照、组件库全状态、无障碍标准
- `astra-prototype.html` — 五页可交互原型：实时助手 / 音频工作台 / 会议复核 / 模型训练 / 管理设置
- `README.md` — 设计决策、令牌对照、落地路径、已知取舍
- `overview.md` — 任务概述

**美学方向：档案室 + 精密仪器。**
刻意避开通用 AI 审美（深蓝黑底 + 紫蓝渐变 + 霓虹青 + Inter）。改用：
- 暖纸色中性底，OKLCH 色相 55–75、彩度 ≤0.015
- 靛墨主色（色相 248，低彩度深蓝），朱砂信号色（色相 42）仅用于「录制 / 处理中」
- Newsreader 衬线做标题，IBM Plex Sans 做界面，IBM Plex Mono 做所有数字（`tabular-nums`）
- 圆角最大 14px，刻意收紧以取仪器感

**四个签名元素**：声纹罗盘（16 根径向柱 + 刻度环，麦克风状态即页面重心）、
时间脊柱（逐字稿左侧连续时间轴）、勘校对照（原文划掉 + 修正上下叠放，窄屏不崩）、
朱砂印（审核状态用印章，实线=终态 / 虚线=待处理，灰度可辨）。

**令牌架构**：两层——原始色阶（`--paper-*` / `--ink-*` / `--vermilion-*`）+
语义令牌（`--bg-*` / `--text-*` / `--accent` / `--live`）。组件只引用语义层，
切主题时只重定义语义层。

**踩过的坑（重要，后续复用）**
1. 图形色与文字色必须拆两套令牌。WCAG 图形 3:1、正文 4.5:1。朱砂作色块 `--live`(0.55) 达标，
   作文字必须用更深的 `--live-text`(0.44)。
2. 深色主题下实心危险按钮要**压暗**而非提亮。直接提亮会让白字只有约 2.4:1。
   方案单列 `--btn-danger-bg`，深色取更深的红 → 4.9:1。
3. 浅色下「有色文字压同色浅底」普遍只有 4.2–4.4:1，所有 `*-text` 令牌需比直觉再深一档。
4. 深色主题不用阴影，靠表面亮度表达层级；行高额外 +0.06。
5. 禁用态用显式令牌（bg-inset + text-disabled）而非整体降 opacity，否则深色下糊成一团。
