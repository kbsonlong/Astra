# 2026-08-28 工作日志

## Astra 项目全面架构分析

对 Astra 局域网语音助手 MVP 进行了完整的项目架构分析，覆盖目录结构、技术栈、代码组织、性能瓶颈、安全隐患和核心业务逻辑。

### 关键发现

- **架构**：后端 FastAPI 分三层（API→Core→Models），前端 React 19 + Vite 7 SPA，Docker Compose 仅运行 Nginx 反代
- **核心管道**：ASR (mlx-audio/Qwen3) → LLM (httpx SSE 流式) → 按句 TTS (piper-tts) → WebSocket base64 推送
- **状态机**：IDLE→LISTENING→REASONING→SPEAKING→LISTENING，generation_id 隔离每次交互
- **测试**：7 个文件 18 个用例，依赖注入式 mock 设计干净

### 主要问题

1. `ws_session.py:38` 传空 messages 数组给 LLM，导致对话无上下文
2. .env 中 API Key "kbsonlong" 过弱
3. 无 CORS / 认证 / 文件大小限制
4. LLM 客户端 aclose() 未在 lifespan 调用
5. 前端 App.tsx 91 行堆积全部逻辑，无组件拆分
6. 前端音频播放无队列，可能乱序
