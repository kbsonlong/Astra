实时语音通话 - 状态机 & 数据流

VAD 自动打断 + 手动按钮双模式 · 全双工交互设计

🔄 核心状态机

State 0
🟢 IDLE 空闲
等待用户发起会话
显示"开始通话"按钮
➡
State 1
🟡 LISTENING 监听中
麦克风录音 + VAD 检测
音频分片上传到后端
➡
State 2
🔵 REASONING 推理中
ASR 转文字 → LLM 生成
流式输出 token
➡
State 3
🔴 SPEAKING 播放中
TTS 流式合成播放
同时保持 VAD 监听打断

⚡ 打断触发路径（双模式）

🎐 路径 1：VAD 自动打断（SPEAKING 状态下）
  1. 前端持续分析麦克风输入音量
  2. 连续 300ms 超过阈值 → 触发打断信号
  3. 立即 WebSocket 发送 interrupt 消息
  4. 后端：
    　· 停止 TTS 合成
    　· 取消 LLM 推理请求
    　· 清空缓冲队列
  5. 立即切回 LISTENING 状态
🖱️ 路径 2：手动按钮打断（任意状态）
  1. 用户点击"停止/打断"按钮
  2. 前端立即停止 TTS 音频播放
  3. WebSocket 发送 interrupt 消息
  4. 后端：
    　· 取消全部进行中的任务
    　· 清空上下文缓冲
  5. 可选：自动进入 LISTENING / IDLE

📦 数据管道 - WebSocket 消息协议

// Client → Server
audio_chunk　　// 二进制音频分片 (PCM 16kHz 16bit)
interrupt　　　// 打断信号，立即停止一切
start_session　// 开始新通话会话
end_session　　// 结束当前会话
// Server → Client
asr_partial　　// ASR 中间识别结果（实时显示）
asr_final　　　// ASR 最终识别结果
llm_token　　　// LLM 流式 token（实时显示文字）
tts_chunk　　　// TTS 音频分片（流式播放）
state_change　　// 状态变更通知 idle/listening/reasoning/speaking
error　　　　　// 错误消息
