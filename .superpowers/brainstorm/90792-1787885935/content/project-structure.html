项目结构 & MVP 功能边界

📁 MVP 阶段目录结构（Monorepo）

Astra/
frontend/　# React Web 前端（MVP）+ 后续 Tauri 壳
src/
components/　# UI 组件（录音按钮、波形图、对话列表）
hooks/　　# WebSocket、录音、VAD、TTS 播放 hooks
store/　　# 会话状态、消息历史
package.json · vite.config.ts
backend/　# Python FastAPI 后端（MVP），后续替换为 Go 网关
app/
api/　　　# HTTP + WebSocket 路由
ws_session.py　# 语音会话 WebSocket 核心
core/　　　# 业务逻辑
session_manager.py　# 会话状态机
pipeline.py　　　# ASR → LLM → TTS 流水线
interrupt.py　　　# 打断逻辑（任务取消）
models/　　# 模型服务客户端
llm_client.py　# Ollama → 后续换 llama-server
asr_client.py　# Faster-Whisper
tts_client.py　# Piper TTS
requirements.txt · Dockerfile
deploy/　# 部署配置
docker/　　# Docker Compose + 各服务 Dockerfile
models/　　# 模型文件下载脚本（GGUF 等）
docs/　　# 设计文档、API 文档
docker-compose.yml　# MVP 一键启动：Ollama + FastAPI + 前端静态服务
.gitignore · README.md

🎯 MVP 功能边界（绿色 = 包含 · 灰色 = 后续迭代）

🎙️ 实时语音通话（核心）
开始/结束通话按钮
麦克风录音（16kHz PCM）+ 波形可视化
VAD 自动打断 + 手动打断按钮
ASR 实时识别文字显示（中间+最终结果）
LLM 流式回复文字显示
TTS 流式播放（支持随时打断）
💬 会话管理
单次通话多轮对话上下文（LLM 记忆 10 轮）
对话历史文字展示（用户/助手气泡）
会话持久化（保存到本地数据库）
历史会话列表 & 回溯
🧠 模型配置
配置页面：模型名称、temperature、system prompt
模型服务地址配置（Ollama / ASR / TTS endpoint）
多模型切换 & 模型热更新
📱 跨平台 & 其他
React Web 端（Chrome/Safari 支持）
Docker Compose 一键启动（Mac mini 部署）
Tauri 桌面端封装（macOS/Linux）
移动端（iOS/Android）
翻译助手模块
