Astra 语音助手 - 整体架构概览

基于 Mac mini 16G 本地模型底座 · 实时语音通话 · React + Tauri 跨平台

🏗️ 系统架构分层

📱 客户端层（Client Layer）
MVP: React Web 页面（浏览器访问）
桌面端: Tauri 封装（macOS / Linux）
移动端: 后续 Capacitor 或 PWA（iOS / Android）
→ 负责：录音采集、TTS 播放、实时 UI 交互
⬆⬇ WebSocket + HTTP API
🔌 后端网关层（API Gateway）—— 部署在 Mac mini
会话管理 · 音频流调度 · VAD 端点检测
打断逻辑 · 状态机编排 · 模型接口适配
→ 推荐技术栈：Rust Axum 或 Python FastAPI
⬆⬇ 本地进程间调用
🧠 模型服务层（Model Serving）—— Mac mini 本地
LLM 推理（7B~8B 量化） · ASR 语音识别 · TTS 语音合成
→ 候选方案：Ollama / llama.cpp + Whisper / Faster-Whisper + Piper / Coqui

📋 需求确认汇总

MVP 范围
语音助手优先（翻译助手后续迭代）
交互模式
实时语音通话 · 支持打断插话
模型策略
效果优先 · 7B~8B 量化 · 2~4s 延迟
技术栈
React + Tauri · Mac mini 部署模型+后端
