# Astra 音色库页面线框稿

> 更新时间：2026-10-01
> 关联方案：[音色库页面方案](tts-voice-library-page-plan.md)
> 说明：低保真交互线框稿，用于确认信息层级、状态和关键操作；不代表视觉样式。

## 1. 用户路径

```text
音色库列表
  ├── 新建音色 → 基本信息 → 上传参考音频 → 确认授权 → 试听/启用
  ├── 打开音色 → 查看参考音频、版本与授权 → 试听/创建新版本/归档
  └── 进入实时助手 → 选择已启用音色 → 开始固定版本的会话
```

交互规则：

- “用于本次会话”跳转到实时助手，并预选此音色的当前 active revision；
- 草稿、归档、撤销音色不显示“试听”和“用于本次会话”；
- 点击卡片任意非按钮区域进入详情；
- 空列表展示创建入口和参考录音要求，不显示空白卡片区。

会话开始后选择器锁定，显示快照信息：

```text
当前回复：小雅 · IndexTTS MLX · r3  [i]
此会话已固定该音色版本；结束通话后才能更换。
```

`*` 已选择多引擎路由；仅在 `TTS-00A` 实现完成、对应引擎已启用且通过用户开放门禁时显示。

选择器规则：

- 只列出 `active + consent confirmed + 当前引擎兼容` 的音色；
- 当前 backend 不兼容或 IndexTTS 未就绪时，不显示相关克隆音色；默认选中“系统默认”；
- 用户从音色库点击“用于本次会话”时，跳转后预选相应版本，但仍须由用户点击“开始通话”；
- 会话开始消息必须传递 `voice_id` 和 `voice_revision`，系统默认音色不传快照字段。

## 8. 响应式优先级

窄屏时使用单列：筛选控件换行、音色卡片纵向排列、详情从右侧抽屉改为全屏页面。不要在窄屏隐藏授权状态、当前 revision 或“当前回复音色”；这些是安全和可解释性所必需的信息。

## 9. 评审问题

实施前需要确认：

1. 首期是否仅支持 WAV，还是同步提供本地 m4a/mp3 转码；
2. IndexTTS 真机验收未通过时，是否允许用户创建草稿及显示实验性入口；
3. “设为本次会话音色”是仅预选当前浏览器会话，还是需要新增持久化的个人默认偏好；
4. 多引擎路由的默认回退引擎是否仅限 Piper，还是允许 MLX Audio 作为后备系统声音。
